# デプロイ手順

このプロジェクトは GitHub と Vercel が連携しており、GitHub の `main` ブランチにプッシュすることで自動的に Vercel へデプロイされます。

## 基本的なデプロイの流れ

以下のコマンドを順に実行することで、最新の変更をデプロイできます。

```bash
# 1. 変更したファイルをステージングに追加
git add .

# 2. 変更内容をコミット（メッセージは適宜変更してください）
git commit -a -m "コミットメッセージ"

# 3. リモートリポジトリへプッシュ
git push
```

## 注意事項

- **Vercel のデプロイステータス**: プッシュ後、Vercel のダッシュボードからデプロイの進捗状況やログを確認できます。
- **環境変数**: 新しい環境変数が必要な場合は、Vercel のプロジェクト設定から追加し、再デプロイを行う必要があります。
- **Next.js 15 の制約**: Next.js 15 では Cookie の読み取りなどの API が非同期（Async）になっているため、認証ロジックなどの変更時には注意が必要です。
